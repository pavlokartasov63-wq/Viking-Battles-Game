RU:

Viking Battles - это динамичный хардкорный 2D экшен-платформер с элементами RPG, разработанный на Python с использованием библиотеки Pygame. Вам предстоит взять на себя роль отважного викинга, сражающегося с волнами свирепых врагов, монстров и боссов на арене, а также развивать своего персонажа в мирном городе. Игра сочетает в себе элементы скилл-ориентированного боя в реальном времени, глубокую прокачку характеристик и защиту от читерства.

EN:

Viking Battles is a fast-paced, hardcore 2D action platformer with RPG elements, built in Python using the Pygame library. Players take on the role of a valiant viking, fighting waves of fierce enemies, monsters, and bosses in the arena while upgrading their character in the safety of the town. The game combines skill-based real-time combat, deep progression systems, and a robust anti-cheat protection mechanism.

First, run install.bat, then run install_modules.py as an administrator.
Never attempt to alter the statistics; this will 100% result in a reset.
To start game click on start.bat.
